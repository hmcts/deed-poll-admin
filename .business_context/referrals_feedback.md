# Referral feedback

I've been through the referrals functionality as a caseworker and as a judge. This is what I have found so far. 

# Disjointed caseworker experience

The functionality is currently split accross two tabs and it's not completely clear on how it works. I entered details on the refer to master tab then had to go to the referral tab to refer it to a master. I think the refer to a master tab should be incorperated into the referrals tab. So a user can see closed and open referrals and create a new one all in the same place. 

# Referral data not displayed

After a master hsa made a direction on the referral, as a caseworker I couldn't see what this detail was. A caseworker, and admin-caseworker, should be able to see what the master has directed, including any notes. 

# A referral alerting

The attenion banner should only show the total number of referrals where a direction has been made by a judge which needs caseworker attention. Once the application has been dealt with after the direction, it drops off the attention banner numbers. I did like the way that I could view referrals so want that to be retained. 

# Status not updating

As a caseworker looking at the referrals tab, after a master has made a direction which has been saved, the text under the referral is misleading and not relevant to the state the application should be in after the referral has been made and a direction issued. 

# Withdrawal still available

The option to withdraw a referral is still available after a master has made a direction and effectivley closed the referral. After a direction has been made a caseworker or a admin-caseworker should not be able to withdraw it. 

# Missing casenotes

When a referral has been made a record should be added to the case note to show that a referral has been made, when, and by whom. When a master claims the referral, a note should be made etc. At each point of the referral lifecycle, an entry should be added to the casenotes. 

# Referral state label

The referral state labels are not updating and reflecting the current state of the referral. For example, says referred to master after a direction has been made. 

# Missing claimed referral

I started as a master then claimed a referral, switch personas to a caseworker, then when back to the master role. I couldn't see the referral I had claimed.
